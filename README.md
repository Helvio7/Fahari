Fahari

Uma plataforma web para facilitar a procura por bolsas de estudo e visa a resolver os problemas de encontrar sites autênticos sobre bolsas de estudo.

 🚀 Status do projeto
✔️ Em desenvolvimento  

## 📌 Funcionalidades
- [x] Cadastro e login de usuário simples
- [x] Cadastrar bolsas de estudo
- [x] Permitir os usuário observarem as bolsas cadastradas

 🛠️ Tecnologias utilizadas
- HTML, CSS, JavaScript
- PHP
- MySQL
